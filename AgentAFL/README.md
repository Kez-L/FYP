# AgentAFL

LLM-assisted seed injection for a live AFL++ fuzzing campaign: when coverage
plateaus, ask an AI for new seeds, check they're actually useful, and feed the
good ones back in.

## Running it

1. Have a live AFL++ campaign running (see `AFLPlus/`).
2. Start `plateau_watch.py` — it watches the campaign's instances and writes
   coverage stats to `plateau_log.csv` (no side effects otherwise).
3. Start `agentafl_orchestrator.py` — it periodically checks `plateau_log.csv`
   for a genuine plateau. When one hits, it calls `build_context_generic.py`
   to assemble a prompt from live campaign state, sends it to an AI (Gemini
   at the moment), extracts candidate seeds from the response, and injects
   the useful ones into the campaign via `afl-addseeds`.

## Files

- `plateau_watch.py` — passive logger, watches AFL++ instances and writes
  `plateau_log.csv`.
- `agentafl_orchestrator.py` — main loop: detects plateaus, builds prompts,
  calls the AI, injects new seeds. Logs every cycle to `cycles.jsonl`.
- `build_context_generic.py` — builds the SYSTEM/USER prompt sent to the AI,
  from whatever's currently on disk in the campaign.
- `evaluate_seeds.py` — checks whether AI-generated candidate seeds hit new
  coverage, mostly used for logging/record-keeping on what happened each run.
- `generate_report.py` — rarely used, just to tidy up run data into a
  nicer-looking report when needed.
- `xml_utils.py` — shared helpers (e.g. XML well-formedness checks) used by
  the scripts above.

## Folders

- `AFLPlus/` — AFL++ itself, plus the fuzzing targets (libtiff, libxml2),
  their builds.
- `afl-output-libtiff/`, `afl-output-libxml2/` — live AFL++ campaign output
  directories per target.
- `agentafl_runs` — seeds generated by agentafl_orchestrator during runs, and also generated reports
  for those runs
- `ai_generated_seeds_samples/` — sample seeds generated at times to test different prompts
- `plateau_log.csv`, `plateau_log_libtiff.csv` — coverage logs written by
  `plateau_watch.py`.

**OVERALL STRUCTURE**

# Stage 0 - Baseline
- Gives AI information of name of type of file format it is fuzzing. 
- To serve as baseline

# Stage 1 Raw
- Takes 2 'good' seeds from around 400 bytes and 2 'bad' seeds which have been previously generated by AI, which have not improved coverage. The bad seeds have edge sets which are different enough, which is how they get selected.

# Stage 1 Raw - No feedback
- same as previous, but without the 2 bad seeds, to be used as baseline to see if feedback even helps

# Stage 2 Coverage
- similar to stage 1
- mechanism for 'good' seeds, is ones with more coverage, there is a cap on seed size
- Seeds must be between x and y bytes size, then the ones with more coverage are selected

# Stage 2 Coverage per byte
- 'good' seeds are selected based on how much coverage (how many edges) per byte 

# Stage 2 Rare Coverage
- 'good' seeds are selected, based on if the coverage they have, isn't covered by many other seeds
- inspired by AFLFast

# Stage 2 neg hypothesis
- replaces 2 bad seeds with the following mechanism
1. Collects previous bad AI seeds, groups them based on edge similarities
2. sends a question to AI with a group of seeds that are similar and 'bad' (did not produce edge coverage) and asks AI to analyse and create a hypothesis of why
3. does same as stage 1, but adds the hypothesis generated previously in the prompt as well

(does have double the number of calls)
(takes a lot longer)

# Stage 3 rotation
- has 3 phases of generation, 3 sentances which get swapped, to try create more variety
- based off of fuzz4all
- has not done well in the testing.

**RESULTS**
Testings have been done on XML and iCalender
sending 10 pings to AI, getting it to return 5 seeds with each ping

**XML**
Coverage focused ones did best:


Number of edges: total number of edges
Seeds With Coverage: Total number of seeds that produces more coverage
New Edge Contributors: Number of seeds, that contributed, and didn't duplicate with previous seeds (will always be <= seed with coverage). Basically if they were added one after another, this is the number that would be considered producing new coverage
New Edge Sets: Number of seeds, that produce unique edge sets. (will be between new edge contributors and seeds with coverage)
